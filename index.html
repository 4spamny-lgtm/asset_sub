시세 연동

API 키는 브라우저에 넣지 않고 Netlify Function 또는 Supabase Edge Function 같은 프록시를 권장합니다.
이 Netlify 패키지로 배포하면 두 주소가 자동 설정됩니다. 별도 입력이 필요 없습니다.
현재가: GET ?ticker=AAPL&market=US → {"priceKrw":180000,"price":130,"fx":1384.6}.
과거가격: GET ?ticker=AAPL&market=US&date=2026-05-31 → 같은 형식으로 반환합니다.
월말 기록 시 티커가 있는 평가금액 기준 자산은 해당 기준일의 주당 원화가격을 조회해 추정수량을 자동 저장합니다.
스크린샷 평가금액 ÷ 해당 월말 주당 원화가격으로 계산하며, 실제 보유수량을 덮어쓰지 않습니다.

ChatGPT에 복사할 문구

직접 확인하고 싶다면

  1. S&P500 200일선 상회비율: 미국 증시가 일부 대형주만 오르는지, 시장 전반이 함께 오르는지를 보는 시장 폭 지표입니다.
  2. S&P500 고점 대비: 미국 대형주 전체가 최근 고점에서 얼마나 조정받았는지 보여줍니다. 조정폭이 커질수록 가격 부담은 낮아질 수 있지만, 하락 이유도 함께 봐야 합니다.
  3. 미국 10년물: 주식·채권의 할인율 부담을 보는 핵심 금리입니다. 높을수록 고평가 성장주에는 부담이 커질 수 있습니다.
  4. Nasdaq-100 고점 대비: 0%에 가까우면 고점권, -10%면 최근 52주 고점보다 10% 내려온 상태입니다.
  5. 금 고점 대비: 금이 고점권인지 충분히 조정받았는지 비교하는 값입니다. 금리·달러 흐름과 함께 해석합니다.
  6. KOSPI 고점 대비: 국내주식의 가격 부담과 조정 정도를 간단히 비교하는 값입니다. 환율·반도체 업황 등도 함께 고려합니다.

시장 신호 업데이트

월 1회 정도만 갱신해도 충분합니다. 월말 자산 JSON을 기준으로 다음 달 초 시장환경을 확인해 입력해두세요.

지금 시장과 내 보유비중을 기준으로 다음 점검 때까지 실제로 무엇을 할지 적습니다.
현재 행동을 바꾸는 트리거입니다. 고점 대비 조정폭·금리·시장폭처럼 다시 확인 가능한 숫자로 적는 것이 좋습니다.
현재 수치를 위 조건과 대조해 충족 · 일부 충족 · 미충족으로 판단합니다.
문장은 기본적으로 일반 글씨로 표시됩니다. 필요한 부분만 **별표 두 개**로 감싸면 대시보드에서 굵게 표시됩니다. 예: 현재 **금리 부담이 높음**
숫자 찾기가 어렵다면 대시보드의 시장 신호 옆 ?를 누르세요. ChatGPT에 그대로 복사할 수 있는 월 1회 확인용 문구를 넣어두었습니다.

월말 기록

현재 스크린샷 기준 평가금액을 저장합니다. 과거가격 API가 설정되어 있으면 티커가 있는 평가금액 기준 자산의 추정수량도 자동 계산해 함께 저장합니다.

자산에 소유자(공동관리)나 상품유형을 나중에 지정하면 이미 저장된 과거 기록에는 반영되지 않아, 대시보드의 ‘현재’와 ‘월말’ 합계가 어긋날 수 있습니다. 이 버튼이 모든 달의 기록을 현재 자산 설정에 맞춰줍니다. 금액은 건드리지 않습니다.

AI 가공 데이터 업데이트

스크린샷을 AI에 주고 아래 규격의 JSON만 받아 붙여넣으세요. AI가 확실하지 않은 수량/티커는 null 또는 빈 문자열로 두게 하는 것이 핵심입니다.

주식 외에 입출금·예적금도 같은 방식으로 넣을 수 있습니다. 항목에 "category"를 붙여주세요 — "cash"(입출금·파킹) / "deposit"(예금·적금) / "bond" / "fund" / "realestate" / "other". 생략하면 주식으로 처리됩니다. 예적금은 interestRate(연이자율), maturityDate(만기일)도 같이 넣으면 만기·이자 추정이 붙습니다.
JSON을 붙여넣고 ‘미리보기’를 누르세요.
